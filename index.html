Graduation Project • 2025–2026

Lost in Egypt — Case Study

Flutter • Firebase • AI/ML • Google Maps API • Computer Vision

⚠️ The Problem

Egypt possesses thousands of historic sites, yet international visitors and domestic travelers frequently face fragmented information, language barriers at historic sites, and difficulty identifying uncaptioned ancient monuments without hiring private guides.

💡 The Solution

Lost in Egypt acts as an all-in-one smart tourism companion. By combining on-device computer vision for instant monument identification with AI itinerary generation, travelers receive tailored, educational exploration in their native language (English & Arabic).

🏗️ Technical Architecture & Implementation

Developed with Flutter for fluid 60fps cross-platform mobile performance across Android and iOS. Integrated with Firebase for user profile authentication, real-time community stories, and cloud storage. The application embeds the Google Maps SDK for route rendering and waypoint geometry, coupled with on-device computer vision models for fast landmark inference.

⚙️ Key Engineering Features

  • AI-Powered Trip Planning: Dynamically optimizes travel routes based on days available and user interests.
  • Camera Landmark Recognition: Computer vision model identifies ancient monuments and displays curated historical context.
  • Interactive Maps & Navigation: Real-time GPS location tracking with historic pins and directional navigation.
  • Bilingual Localization: Full Left-to-Right (LTR) and Right-to-Left (RTL) Arabic typography and interface layout.
  • Community Hub: Safe community space for travelers and local guides to exchange verified reviews and photos.
